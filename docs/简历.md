# 项目经历

## 善阅坊 —— 小说阅读分享平台

**技术栈**：SpringBoot 3，Redis，PostgreSQL，RabbitMQ，MyBatis-Plus 
**项目描述**：个人开发的小说阅读与书友互动平台，实现小说书库、书架、阅读打卡、点评、点赞收藏、书友动态广场等核心功能，采用微服务架构保证系统高可用与水平扩展能力。

**主要工作**：

- 负责项目整体后端架构设计与核心接口开发，基于 PostgreSQL 设计小说信息、用户、书架、点评、互动等数据表，合理设计字段与索引，保证数据结构清晰、查询高效。
- 使用 Redis 实现热门小说、阅读排行、点赞状态、用户登录态等缓存，解决缓存穿透、击穿问题，大幅降低数据库压力，接口响应速度提升明显。
- 引入 RabbitMQ 实现点评发布、阅读打卡、积分更新、动态推送等异步处理，将同步逻辑解耦，提升接口吞吐量，避免高并发下阻塞。
- 独立完成小说列表、详情、书架增删、点评提交、点赞收藏、阅读打卡等接口开发，处理参数校验、异常捕获、事务控制等细节，保证接口健壮性。
- 对核心接口进行测试与优化，排查慢查询、缓存不一致、消息重复消费等问题，积累从需求分析到编码、调试、优化的完整项目经验。

## 可信数据空间平台

**技术栈：**Spring Boot 3，Spring Data JPA， Apache Dubbo 3，Alibaba Nacos，MySQL，Redis，Kubernetes Java SDK，MinIO
**项目简介：**负责“可信数据空间服务平台 & 连接器”后端开发，搭建“平台侧微服务 + 多类型连接器”的架构，实现数据空间内各参与方通过连接器安全接入、发起申请及基于 TEE 的隐私计算任务。
**主要工作**

- 在平台侧实现“连接器管理”模块，基于 Dubbo + JPA 完成连接器注册、心跳上报、状态更新、分页查询，并结合 Nacos 做服务发现与可用实例列表输出。
- 设计通用申请模型（ApplicationRequest），实现申请创建、收到/发出列表分页查询与审批（同意/拒绝）接口，统一封装返回结果与业务异常。
- 设计并实现基于 CP-ABE 的数据安全访问控制体系，通过 SecurityLabel 将数据哈希、所有者签名与访问策略密码学绑定，构建三层完整性验证机制，并以混合加密方案（ABE+AES）解决大文件性能问题，实现数据全生命周期的细粒度安全保护。
- 在连接器端实现与平台对接的注册/心跳/注销逻辑及申请、TEE 控制器，对外暴露 REST API，内部通过 Dubbo 调用平台服务，打通“边缘连接器 → 平台编排 → TEE 计算”的完整链路。
