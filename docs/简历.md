# 项目经历

## 善阅坊 —— 小说阅读与 AI 阅读助手平台

**项目类型**：个人独立项目

**技术栈**：Java 17，Spring Boot 3，Spring Cloud Gateway / Nacos / OpenFeign，MyBatis-Plus，Sa-Token，PostgreSQL，Redis，RabbitMQ，Elasticsearch，Milvus，Neo4j，Spring AI，Docker Compose，Prometheus，OpenTelemetry

**项目描述**：面向小说阅读场景的微服务平台，包含书库、书架、阅读进度、点评互动、签到积分等基础能力，并新增独立的小说 AI Agent。Agent 通过悬浮按钮和独立 Agent 中心提供问答、推荐、人物关系图谱、伏笔线索、无剧透回顾等能力。

**主要工作**：

- 负责整体后端架构和核心业务开发，将网关、用户、小说、点评、互动、签到和 Agent 拆分为独立服务，使用 Nacos 完成服务发现与配置管理，使用 OpenFeign 完成服务间调用。
- 设计 `canonicalBookId` 作品主键、书源映射、内容版本和 SHA-256 账本，处理多书源归并、章节版本幂等、失败重试和删除清理，避免同一本作品因书源不同产生重复索引。
- 独立实现 LightRAG-only 小说问答链路：实体识别、受阅读进度约束的一至两跳局部图扩展、章节/图卡片选择、Milvus 向量召回、Elasticsearch 关键词召回、PostgreSQL 权威片段兜底和本地混合 Reranker 精排；通过 36 条局部边预算和统一 Prompt Token 预算控制上下文规模，不引入传统 GraphRAG 全图检索。
- 建设 RabbitMQ 异步知识索引流水线，完成章节切片、摘要、Embedding、图谱抽取、向量/关键词投影、重试和死信处理。PostgreSQL 保存权威证据，Neo4j 保存人物/事件关系投影，Milvus 保存章节、角色、事件和社区向量，Elasticsearch 提供关键词检索。
- 基于 Spring AI 封装 OpenAI-compatible 模型适配层，支持 DeepSeek 平台模型和用户自带 API（BYOK），实现 SSE 流式对话、结构化输出、Tool Calling、MCP 只读工具、模型路由、Prompt 版本和调用 Token 统计；平台模型通过积分冻结、结算和退款控制试用额度。
- 完成悬浮 Agent、Agent 中心和管理台前端，落地无剧透剧情回忆胶囊、伏笔雷达、相似书 DNA、动态书架管家、角色访谈和阅读分岔地图等功能，并让推荐、图谱和引用跳转回真实作品及章节。
- 实现服务端阅读边界裁剪、图谱审核和置信度门禁，阻止未读章节、待审核关系和整本原文进入回答上下文；通过 Gateway-Agent 信任令牌、只读工具白名单、RBAC、限流、超时、失败冷却和降级策略保护 Agent 链路。
- 接入 Prometheus、OpenTelemetry、Jaeger 和 Docker Compose，编写索引、图谱故障、MCP、LightRAG 预算、Reranker 和端到端验证脚本；后端九模块回归测试、Agent 测试、前端构建和 Compose 配置均纳入 CI 质量门禁。
