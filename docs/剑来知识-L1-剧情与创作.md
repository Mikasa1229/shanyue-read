## 2. 剧情总览与创作背景（L1）

### 公开知识基准中的主线阶段


主线可以抽象为“贫苦少年求生与修行 → 骊珠洞天机缘与离别 → 多天下游历 → 剑气长城战争与隐官责任 → 文庙和天下格局 → 宗门建设与文明秩序”。回答剧情问题时必须把抽象阶段转换成当前阅读边界内的章节证据，不能只依赖本表。

### 3.1 陋巷少年

- 陈平安五岁成为孤儿，本命瓷与长生桥早期受损，失去直接成为练气士的机会。
- 他在小镇龙窑跟随姚老头学习拉坯、制瓷，并通过采药和帮工维持生活。
- 骊珠洞天吸引外乡人寻找机缘，陈平安因弱小和谨慎错过多次机缘，同时与宁姚相遇并共同面对危险。
- 齐静春在小镇守护百姓并关注陈平安，相关印章、文圣传承和骊珠洞天破碎构成早期主线。

### 3.2 初次远行

- 陈平安护送李宝瓶、李槐、林守一以及于禄、谢谢前往大隋山崖书院。
- 阿良、魏檗、崔诚等人物在这一阶段影响陈平安的剑道、体魄和江湖经验。
- 落魄山、竹楼和后续弟子/护法关系逐渐形成。

### 3.3 送剑与藕花福地

- 陈平安前往剑气长城为宁姚送剑，途中经历老龙沟、倒悬山等关键地点。
- 他在剑气长城与曹慈问拳，并因送剑任务进入更大的天下格局。
- 藕花福地阶段引出裴钱、魏羡、朱敛、卢白象、隋右边等重要人物，陈平安的师徒和山门关系开始成形。

### 3.4 北俱芦洲与剑气长城

- 北俱芦洲经历强化陈平安心境、武胆和远游能力，并结识周米粒。
- 剑气长城阶段，陈平安以外来者身份融入当地，与宁姚、叠嶂等人物建立关系，并以酒馆和印谱等方式参与城市生活。
- 蛮荒天下进攻剑气长城后，陈平安承担隐官职责，组织隐官团队并以有限资源延缓战争、保存火种。

### 3.5 文庙、蛮荒和宗门建设

- 战争之后，陈平安回到浩然天下并参与文庙议事，故事从个人成长扩大到天下秩序和族群冲突。
- 陈平安、宁姚、阿良、左右、白也、郑居中等人物在不同阶段参与蛮荒天下相关行动。
- 落魄山成为宗门，青萍剑宗作为下宗，桐叶洲修复、大渎和各方势力合作成为后期重要线索。
- “天下相撞”阶段涉及浩然天下、蛮荒天下、礼圣等高层力量，属于高剧透内容，不能对低阅读边界用户展开。
