# 书源修复与校验说明

## 本轮新增与修复

- 新增《龙族》（江南）的合法匹配：搜索结果允许“龙族（全集）”以及 I-V 分卷，但会保留作者校验，避免把同人文或网文误认成目标作品。
- 新增《吞噬星空》测试覆盖。
- 固化并校验“笔趣阁77”规则：搜索、目录、首章正文均可用；正文规则使用 `.text` 容器，目录规则使用 `class.list@li@tag.a`。
- 修复重复 biquge7 源的空书名规则：图片链接和书名链接是两个不同的 `a`，不能把第一个图片链接当成书名。
- 新增笔趣阁③（`biquge99.cc`）作为第二个可用候选源。该站搜索接口是 GBK 页面，但接口自动解码后可正常提取中文，不能给模型强制设置错误的 GBK 二次解码。
- 书源导入或启停时清理目录缓存，避免规则已更新但仍返回旧的空目录。

## 可复现实测

```powershell
pwsh -ExecutionPolicy Bypass -File scripts/validate-book-sources.ps1
```

脚本会对所有启用源执行六本书的三段式验收，并在报告中写明失败阶段。也可以用 `-SourceIds` 只测指定源：

```powershell
pwsh -ExecutionPolicy Bypass -File scripts/validate-book-sources.ps1 `
  -SourceIds 309683898734874624,309393999913816064
```

书源站点存在变更、限流、Cloudflare 或地区网络差异时，应重新运行脚本，不要依据历史 HTTP 状态判定可用性。
