## 可复现实测

```powershell
pwsh -ExecutionPolicy Bypass -File scripts/validate-book-sources.ps1
```

脚本会对所有启用源执行六本书的三段式验收，并在报告中写明失败阶段。也可以用 `-SourceIds` 只测指定源：

```powershell
pwsh -ExecutionPolicy Bypass -File scripts/validate-book-sources.ps1 `
  -SourceIds 309683898734874624,309393999913816064
```

书源站点存在变更、限流、Cloudflare 或地区网络差异时，应重新运行脚本，不要依据历史 HTTP 状态判定可用性。

## Legado 源库全量扫描

`book_source/legado/sources` 是本轮书源的候选库。目录中共有 19 个 JSON 文件、9068 条原始记录；先按站点 URL 去重和转换，得到 1652 条可由服务端执行的候选。转换会保留项目运行所需的 Legado 字段：

| Legado 字段 | Reader 运行字段 / 用途 |
|---|---|
| `bookSourceName` / `bookSourceUrl` | `sourceName` / `sourceUrl` |
| `searchUrl` + `ruleSearch` | 搜索 URL、结果列表、书名、作者、封面、书籍 URL |
| `ruleBookInfo` | 详情页字段与可选独立目录页 `tocUrl` |
| `ruleToc` | 章节列表、章节名、章节 URL |
| `ruleContent` | 正文、翻页、`replaceRegex` 清理规则 |

使用以下命令全量转换、导入与校验。扫描过程会在 `artifacts/legado-scan-checkpoint.jsonl` 写入检查点；中断后加 `--resume` 即可续跑。

```powershell
python scripts/convert-legado-sources.py --disabled
python scripts/scan-legado-sources.py --import-candidates --activate-passing-only `
  --stop-after-first-pass --workers 20
```

`--activate-passing-only` 会让候选源临时启用进行实测；至少一本通过才保留启用，其余候选会保持禁用。通过源的可重导入规则包会写入 `book_source/legado-passing-source-rules.json`，完整结果写入 `docs/legado书源全量校验报告-2026-08-14.md`。
