# 《剑来》知识库资料

本目录集中存放仅面向《剑来》的知识分层材料、公开知识基准、前 100 章 RAG/关系迭代报告及专项 Benchmark 方案。

- `剑来网页全量知识文档.md`：知识材料总入口，链接 L0--L7 分层文档。
- `剑来知识-L0` 至 `剑来知识-L7`：身份来源、剧情、世界观、人物关系、修行体系、器物、章节与衍生资料。
- `剑来公开知识基准.md`：公开知识数据的口径与基准。
- `剑来前100章RAG五轮迭代报告.md`、`剑来前100章RAG五轮自适应迭代报告.md`、`剑来前100章RAG三轮关系迭代报告.md`：前 100 章的抽取、关系和检索迭代记录。
- `小说智能体Benchmark评估方案.md`：包含《剑来》真实语料与前 100 章专项的评测口径和执行方式。

跨书泛化报告、项目通用架构、接口压测与求职材料不在本目录，分别保留于 `docs/` 根目录和 `docs/resume/`。
